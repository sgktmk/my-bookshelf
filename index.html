ASIN (10桁)、ISBN-10 (10桁)、ISBN-13 (13桁) のいずれかを入力。 AmazonのURLを貼り付けてもOK（ASINを自動抽出します）

紙の本の裏表紙にあるISBNバーコード（978で始まる方）をカメラにかざしてください。 読み取り後、自動で書籍情報を取得します。

⚙️ GitHub連携設定

設定すると「☁️ GitHubに保存」ボタンで data/library.json を リポジトリに直接コミットできます（手動でのエクスポート＆push不要）。

認証方法A: Personal Access Token

GitHubでトークンを作成 — 対象をこのリポジトリのみに絞り、権限は Contents: Read and write を選択。 トークンはこのブラウザのLocalStorageにのみ保存されます。

認証方法B: OAuthサインイン（Sveltia/Decap互換）
